# RecordForge Trademark Policy

"RecordForge", the RecordForge logo, and related brand assets (in `branding/`)
are trademarks of Prestige Tech. The GPL-3.0 license grants rights to the
*code*; it does **not** grant any right to use the RecordForge name or logo.

## What you may do without permission

- Refer to this project factually as "RecordForge" (e.g. "a fork of
  RecordForge", "built on RecordForge source code").
- Use the unmodified name/logo inside unmodified official builds obtained
  from this repository's release channel.
- Discuss, review, write about, or teach with the project using its name.

## What requires permission or rebranding

- **Forks and modified builds** distributed to others must use a different
  name and logo. You may state that the software is "based on RecordForge
  source code"; you may not present it *as* RecordForge or as an "official"
  build.
- **The official updater channel** (signed GitHub Release metadata and its
  update endpoint) is for official releases only. Self-built binaries must
  not ship configuration that points at the official updater or presents
  update artifacts as official — the updater signature check will reject
  unsigned builds anyway.
- **The license server endpoint** compiled into official builds is operated
  for those builds. Forks must not activate licenses against it or imply
  compatibility with the official Pro program.
- Using the name or logo in a way that suggests endorsement, affiliation, or
  official status (merchandise, hosted services, marketing) requires written
  permission.

## Goal

Trademark is how open-core projects keep a trustworthy official identity
while the code stays free. If you're unsure whether your use is covered, open
an issue and ask before shipping.
