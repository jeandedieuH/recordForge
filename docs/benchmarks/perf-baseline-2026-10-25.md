# Export Pipeline — Phase 0 Performance Baseline (2026-10-25)

Baseline measurements for the synthetic export-benchmark matrix, captured with
the Phase 0 instrumentation (plate-feed per-plane timings, harness encoder
override, ablation specs). Machine: see
[baseline-machine.md](baseline-machine.md) — Dell G15 5511, Intel i5-11400H
(6c/12t), NVIDIA RTX 3050 Laptop, 24 GB RAM, Windows 11.

## Setup

- Harness: `export_harness` release build at `C:/rf-cargo-target/release/export_harness.exe`
  (`CARGO_TARGET_DIR` on C: because the repo drive had ~7 GB free; `RF_HARNESS`
  points the bench runner at it). Built from the Phase 0 working tree with
  `cargo build --release --features export-harness --bin export_harness`.
- FFmpeg/FFprobe: repo sidecars, 9.0.1 gyan.dev essentials build
  (`apps/desktop/src-tauri/binaries/`).
- Fixture: 60 s 1920x1080@30 screen source + mic track + V2 cursor telemetry +
  640x480 webcam clip, generated by `export-synth-spec.ts` (default, not
  `--long`). 30 s exports, 900 frames.

| pair                                 | frames | mean dB | min dB | result |
| ------------------------------------ | ------ | ------- | ------ | ------ |
| software render_abl-plain_chunked    | 900    | 100.0   | 100.0  | PASS   |
| software render_synth_chunked        | 900    | 100.0   | 100.0  | PASS   |
| nvenc render_abl-plain_chunked_nvenc | 900    | 100.0   | 100.0  | PASS   |
| nvenc render_synth_chunked_nvenc     | 900    | 100.0   | 100.0  | PASS   |

the 100 dB cap, audio durations identical), so the `baseline/` renders are
valid references for later-phase pixel-parity gates.

## Notes and caveats

- **Single repeat** — every configuration ran once (`--repeats 1`), so deltas
  under ~10% are inside run-to-run noise (e.g. abl-captions -10.7% vs plain on
  software is a scheduling artifact, not a win). Re-run with `--repeats 3`
  before quoting marginal costs.
- **Chunk counts differ by encoder** — the auto config split the 900 frames
  into 12 chunks across 6 workers under software, but only 6 chunks across 3
  workers under NVENC (consumer NVENC caps simultaneous encode sessions, so
  the dispatcher clamps chunk parallelism). Cross-encoder comparisons are
  wall-clock only.
- **Plate feeds only exist with planes** — `cursor`/`items` columns are zero
  for ablations without cursor effects or display items; `camera` overlays run
  through the ffmpeg filter graph, not the plate path, so its cost shows up in
  `compose`/`speed`, not the plate columns.
- **Full "all features" pipeline is producer-starved** — `synth_chunked` spent
  ~42.3 s of raster time across plate workers vs 33.6 s compose; cursor raster
  dominates the plate cost (39.6 s of 42.3 s), then pack (6.1 s) and items
  (2.7 s). Keys raster is ~0 (no keystrokes in the fixture).
- Scratch renders written to `%TEMP%/rf-bench` during the runs were copied into
  each fixture dir as `render_*.mp4` and frozen under `baseline/`.
