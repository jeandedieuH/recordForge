# RecordForge 2.5.5

## Fixes

- **Cursor tracks the screen through camera layouts in GPU exports.** When
  a camera layout moved or widened the screen (for example a
  picture-in-picture layout that enlarges the frame), the GPU renderer
  still mapped the cursor through the base screen rect — the pointer
  landed visibly shifted from where you actually pointed. It now follows
  the same screen windows the compatibility renderer uses, so both paths
  land the cursor identically.
- **Glass Loupe magnifies the region under the lens.** During
  camera-layout windows the loupe sampled the screen at its base position
  instead of the rect it was actually drawn into, so the magnified content
  didn't match what sat under the lens.

## Internal

- `cursor_screen_windows` (formerly `side_by_side_screen_windows`) merges
  side-by-side slots and camera-layout rest poses into the cursor's
  screen-rect window table using the compatibility merge order; the loupe
  sample square now normalizes against the per-frame destination rect.
- Unit coverage added for layout windows, merged side-by-side + layout
  spans, and the constant-rect fast path in
  `src-tauri/src/exports/gpu/mod.rs`.
- Workspace version bump to 2.5.5 across all packages; versions earlier
  than 2.5.5 marked unsupported in SECURITY.md.
