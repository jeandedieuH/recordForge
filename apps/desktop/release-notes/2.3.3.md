# RecordForge 2.3.3

## Highlights

- **The timeline now renders clips as seamless run-based strips.** Adjacent
  clips in the same run share visual continuity — the run gets a single
  label and unified corner rounding instead of drawing every clip as a
  separate card — making dense timelines easier to read at a glance.
- **Timeline editing gestures are smoother and more predictable.** Dragging
  clip edges now auto-scrolls the timeline when you reach the viewport
  edge, and a dedicated gesture overlay plus hover line give clearer
  feedback while trimming and arranging clips.

## Improvements

- Lane theming is consolidated into shared color and icon tokens, so audio,
  video, zoom, and camera lanes read consistently across the timeline,
  minimap, and track headers.
- Audio lanes now show a fade hint affordance, and the audio envelope and
  waveform rendering were tidied up alongside the new lane layout.

## Internal

- Timeline gesture math and clip-run layout are covered by new unit tests
  (`timeline-gesture-math`, `timeline-clip-runs`).
