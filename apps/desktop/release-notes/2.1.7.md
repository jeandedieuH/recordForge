# RecordForge 2.1.7

## Improvements

- Export deliveries are now tracked per job: Instant Share and YouTube uploads
  run as post-export deliveries with live progress, and a failed upload no
  longer fails the export itself — the rendered file always stays on disk.
- Added a retry action for failed deliveries, so a dropped Instant Share or
  YouTube upload can be re-run without re-rendering the video.
- YouTube auto-publish preferences (privacy, attach captions, captions
  language) are now remembered per project.
- Hardened the Google/YouTube sign-in flow — concurrent attempts are
  deduplicated and abandoned callbacks time out cleanly instead of hanging.

## Removed

- Removed the virtual background, brand kit (watermark and intro/outro
  cards), studio audio mastering, and auto-reframe Pro features. Projects that
  used them still open and export normally; the settings are simply ignored.

## Fixes

- The FFmpeg setup script now retries transient download failures with
  backoff and uses the correct fallback URL for macOS Apple Silicon builds.
