# RecordForge 2.3.5

## Improvements

- **Refreshed the default cursor shape.** The built-in arrow cursor — used as
  the fallback when a recording's captured cursor can't be matched to a known
  system shape, and shown by the "Recorded / System" cursor preset — now uses a
  modern stemless design with rounded corners and cleaner geometry. It reads
  better at small sizes in the editor preview and in exported videos.

## Internal

- Cursor preset SVGs (`recorded-system`, `shape-arrow`) were rebuilt with
  arc-based rounded geometry; the cursor-engine WASM artifact and
  `assets.json` were regenerated to match.
