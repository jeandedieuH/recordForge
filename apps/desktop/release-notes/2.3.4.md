# RecordForge 2.3.4

## Fixes

- **Fixed the editor playhead jumping backwards around timeline cuts.**
  Preview playback now maps each presented frame to the timeline segment the
  playhead already occupies, so a stale frame from a retired media slot — or
  a frame belonging to a range you deleted — can no longer drag the playhead
  back mid-playback.
- **Smoother transitions between timeline segments.** At a cut, the preview
  now briefly holds the last frame (up to ~180 ms) while the next segment's
  pre-rolled standby finishes seeking, then swaps cleanly instead of
  flickering or bouncing the playhead. Gaps and end-of-timeline stops are
  handled as explicit states rather than falling out of frame timing.

## Internal

- The cut-transition decisions are extracted into a dedicated, tested module
  (`cut-transition.ts`), and the shared `previewSegmentSourceMs` mapping now
  lives in `@recordforge/editor-core` so the preview and its tests use one
  implementation.
