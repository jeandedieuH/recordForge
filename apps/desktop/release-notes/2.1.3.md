# RecordForge 2.1.3

## Highlights

- **Leaner, faster installs** — removed the bundled `tract-onnx` inference
  runtime and the virtual-background model pipeline, shrinking the download
  and cutting startup and export overhead.
- **Streamlined Finishing panel** — the editor task now focuses on what
  ships reliably everywhere: keystroke badges and on-demand processed
  previews through the real export pipeline.
- **Same core workflow** — Smart Cut (Pro), keystroke overlays, multi-format
  export, resumable YouTube uploads, and direct publishing (Instant Share,
  BYO S3, YouTube) are unchanged.

## Removals

- **Virtual background for webcam** — the background replace/blur feature
  and its in-app model download have been removed, along with the ONNX
  runtime that powered it.
- **Studio Audio mastering** — the noise-reduction and loudness-target
  controls have been removed from the Finishing panel.
- **Brand kit** — the brand watermark and intro/outro cards have been
  removed from exports.

## Fixes

- Security support policy updated: versions below 2.1.3 are no longer
  supported.
