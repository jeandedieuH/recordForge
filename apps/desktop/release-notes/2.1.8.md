# RecordForge 2.1.8

## Improvements

- Expanded cursor shape recognition: recordings now detect 7 additional
  cursor shapes — single-direction resize arrows (up, down, left, right),
  vertical text I-beam, context menu, and drag-alias/link cursors — so the
  rendered cursor matches what you saw on screen more often.
- macOS capture now recognizes more native cursor types, including
  directional resize cursors, vertical-layout I-beam, contextual menu, and
  drag link/copy cursors (macOS 14+).
- Linux/X11 cursor detection now covers common Xcursor theme aliases, so
  non-default cursor themes resolve to the correct shape instead of falling
  back to the arrow.
