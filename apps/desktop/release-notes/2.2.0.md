# RecordForge 2.2.0

## Highlights

- **Close to tray is now the default.** Closing the window keeps RecordForge
  running in the notification area so recordings, exports, and uploads are
  never interrupted. The first time this happens, a one-time system
  notification lets you know where the app went. Use **Quit** in the tray
  menu to exit completely — the setting in Settings → General is now called
  "Close to System Tray" if you prefer the old behavior.
- **One instance, always.** Launching RecordForge while it's already running
  now brings the existing window to the front instead of starting a second
  copy with a duplicate tray icon.

## Improvements

- Closing the window while a recording is in progress now parks the app in
  the tray instead of risking the session — a stray click can no longer
  discard a live recording.
- Quitting from the tray menu goes through the normal close path, so the
  editor gets a chance to save unsaved work before the app exits.

## Fixes

- Fixed a case where the app could keep running invisibly with no window
  and no tray icon — closing the window now either parks in a tray that
  actually exists, minimizes to the taskbar, or quits cleanly.
- Fixed the Windows installer reporting that RecordForge is still running:
  second instances no longer hold the executable open, and update installs
  can always close the app.

## Known issues

- On Windows 11 the tray icon may appear in the notification-area overflow
  the first time; drag it out to keep it pinned.
- The close-to-tray hint notification may not appear in unpackaged
  development builds; it works normally in installed releases.
