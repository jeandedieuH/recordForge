# RecordForge 2.2.1

## Highlights

- **Cloud uploads are now a Pro feature.** S3-compatible and Google Drive
  storage providers require an active Pro license. The storage settings
  show the upgrade state clearly, and exports that include an upload step
  check the entitlement before starting so a finished render is never
  followed by a failed upload.

## Improvements

- Uploads kicked off from an export job now resolve the destination up
  front and share the job's progress and retry behavior, so delivery
  failures surface in the same jobs view as the export itself.
- Cursor, overlay, and keystroke recordings now store their frames in a
  packed layout with a precise bounding rect per plane, which reduces
  capture file sizes and speeds up scrubbing and export on projects with
  heavy cursor effects.

## Fixes

- Fixed cloud storage connections appearing available in Settings when
  the license was inactive — the UI now reflects the real entitlement
  instead of letting uploads fail at run time.

## Known issues

- Recordings captured with versions before 2.2.1 keep their original
  stream layout and continue to work; the packed layout applies to new
  captures only.
