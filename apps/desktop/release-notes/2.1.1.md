# RecordForge 2.1.1

## Highlights

- **Updates no longer stall on close** — installing an update now works even
  when "minimize to tray" is enabled or the editor has unsaved changes. The
  app correctly exits so the installer can finish.

## Fixes

- Fixed update installs stalling or failing when the main window's close was
  intercepted by the minimize-to-tray setting; the app now exits while an
  update install is underway.
- Fixed the editor's unsaved-changes prompt blocking an in-progress update
  install; the close guard is bypassed once the installer has been spawned.
