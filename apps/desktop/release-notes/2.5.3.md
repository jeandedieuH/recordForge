# RecordForge 2.5.3

## Fixes

- **Camera AI on standalone webcam recordings.** Camera-only recordings
  store the webcam as its own `webcam.mp4` (or `trim_<id>_webcam.mp4`)
  sidecar file. Analysis and export now probe that file for its real
  decode stream and media metadata instead of assuming the embedded
  stream layout, so AI cutout, background removal, and face tracking work
  on standalone webcam assets — including trimmed ones.
- **Model readiness gating.** Matte and face-tracking steps are now gated
  on their respective ONNX models being downloaded and ready, so jobs
  fail fast with a clear message instead of erroring mid-run.
- **Better encoder/decoder error messages.** FFmpeg stderr details are
  now included in decoder and encoder failure reports, making export
  failures diagnosable from the error alone.

## Internal

- `packages/contracts` gains `isStandaloneWebcamAssetPath` for consistent
  standalone-asset detection across the frontend and Rust; the render
  plan loads camera-AI export artifacts under the standalone key.
- Regression coverage added in `src/lib/camera-ai.test.ts` and
  `packages/media-core/src/render-plan.test.ts`.
- Benchmark/render `out/` directories are now git-ignored; workspace
  version bump to 2.5.3 across all packages and SECURITY.md support
  window updated.
