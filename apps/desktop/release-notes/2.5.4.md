# RecordForge 2.5.4

## Fixes

- **Camera AI mattes stay in sync.** In the editor preview, cutout and
  background-removal mattes now lock to the camera footage clock instead of
  tracking the playhead independently — the cutout no longer lags behind a
  moving person by several frames.
- **Matte alignment in export.** Rendered mattes now match the camera
  stream's timing, crop coordinates, and fit operations, so AI cutout
  exports line up with what you saw in preview.
- **Cleaner cutout previews.** Frame chrome is removed around active
  cutouts so the matte reads cleanly against the canvas.
- **More reliable model downloads.** ONNX model downloads now retry
  against verified mirror URLs when the primary host misbehaves (the
  face-detection model's CDN occasionally serves 404s on a valid URL).
  Downloads also share a User-Agent'd client, and the pinned SHA-256
  still verifies the bytes regardless of which host serves them.

## Internal

- `lockMediaToLeader` keeps follower media elements on a leader clock —
  hard-seeking past half a frame of drift and nudging playback rate
  ±2% below that.
- GPU decode path and render plan updated for matte timing/crop parity;
  regression coverage added in `use-dual-media-slots.test.ts` and
  `packages/media-core/src/render-plan.test.ts`.
- Workspace version bump to 2.5.4 across all packages; versions earlier
  than 2.5.3 marked unsupported in SECURITY.md.
