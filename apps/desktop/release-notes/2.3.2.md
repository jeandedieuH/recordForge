# RecordForge 2.3.2

## Highlights

- **Privacy masks now render on the GPU export path.** Blurred mask regions
  use a new multi-scale blur pipeline in the native compositor, matching the
  compatibility renderer's output. Exports that include privacy masks no
  longer need to fall back to the slower FFmpeg pipeline when Auto or GPU
  rendering is selected.

## Improvements

- Camera overlay decoding on the GPU path now prefetches a frame ahead, so
  webcam footage is already queued when the compositor needs it.
- Export diagnostics now report per-stage transfer timing (decode, upload,
  compose, readback, encode), making it easier to pinpoint where a slow
  export spends its time.

## Fixes

- Fixed GPU exports producing unblurred or mismatched mask regions compared
  to the compatibility renderer — the blur result now passes the
  export-parity gate alongside all other compositor features.
