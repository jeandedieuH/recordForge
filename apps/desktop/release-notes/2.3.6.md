# RecordForge 2.3.6

## Improvements

- **Correct cursor shapes on Linux (Wayland).** Wayland delivers cursor
  bitmaps without a shape name, so recorded sessions previously fell back to a
  generic arrow for most cursor changes. RecordForge now analyzes the cursor
  bitmap itself — ink coverage, bounds, and position — and recognizes hands
  over links, I-beams over text, resize arrows, crosshairs, wait spinners, and
  more. The right cursor now appears in the editor preview and in exports.
- **More system cursors recognized on macOS.** Column/row resize, zoom in/out,
  help, move, cell, and busy-but-clickable cursors now map to their proper
  shapes instead of the default pointer.
- **New cursor silhouettes on Windows.** The pin, person, pen, and up-arrow
  system cursors now render as distinct shapes, and the up-arrow no longer
  appears as the standard arrow.
- **Cursor artwork is tracked by content.** On Wayland, identical cursor
  artwork keeps the same recorded shape even when the compositor reallocates
  its cursor buffer, so cursor identity stays stable during a recording.
- **Preview and export draw the same cursor.** Recorded cursors are no longer
  stretched or shifted to match raw bitmap dimensions, which could make the
  editor preview disagree with the exported video. Both now render the same
  silhouette at the same active point.

## Fixes

- **Ambiguous centered cursors no longer guessed wrong.** Square custom
  cursors with a centered hotspot (move / crosshair / wait / resize) now render
  as the neutral pointer instead of being misclassified as a crosshair, and
  small centered glyphs are treated as the wait cursor.
- **Unmapped cursor kinds are logged.** When a recorded cursor can't be
  matched to a known shape, a one-time warning is written to diagnostics
  instead of silently substituting the default arrow.

## Internal

- Cursor classification is unified through the shared shape map in
  `@recordforge/cursor-engine`: named cursors (Wayland `cursor-shape-v1`,
  XFixes, Xcursor themes) resolve by name, Wayland bitmap-only cursors fall
  back to pixel-feature classification, and geometry heuristics remain the
  last resort on every platform.
- Added classifier tests covering I-beam, resize, crosshair, and conservative
  fallback cases, plus manifest/shape-map consistency checks.
