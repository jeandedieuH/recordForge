# RecordForge 2.1.2

## Highlights

- **Smart Cut (Pro)** — scan the edited timeline for silences and remove them
  in one pass. Detection runs through the real audio graph, so trims, moves,
  speed changes, mutes, and imported audio are all honored, and every
  suggested cut is reviewable before it lands.
- **Finishing panel** — a new editor task that gathers every export-time
  polish in one place: Studio Audio, brand watermark, webcam background, and
  keystroke badges, all editable before you export.
- **Processed preview** — render a real preview through the export pipeline
  on demand to check audio mastering, cards, webcam background, and keystroke
  badges before committing to a full export.
- **Keystroke badges (Pro)** — modifier-combo badges ("Ctrl+C") are now
  configurable (hold time, position, size), preview live on the editor canvas,
  and stay correctly timed through trims, moves, and speed changes. Capture is
  privacy-aware: only real shortcuts are recorded, never plain typing.
- **Studio Audio upgrades (Pro)** — choose a noise-reduction strength and a
  loudness target (YouTube, Podcast, Streaming) for the final mix.
- **Virtual background for webcam** — replace or blur your camera background,
  now including camera-only recordings, with an in-app model download.
- **Direct publishing rework** — Instant Share, BYO S3, and YouTube now run
  as tracked publication jobs: pick a finished export, watch progress in the
  jobs drawer, cancel cleanly, and retry safely thanks to idempotent
  operations. Publishing always uses the export's frozen artifact — file,
  captions, chapters, and title as they were rendered.
- **Multi-format export** — export one project in several aspect ratios as a
  tracked batch; the primary canvas keeps its exact dimensions.
- **Resumable YouTube uploads** — interrupted uploads resume from the
  server-confirmed offset instead of starting over, and completed uploads
  recover their video instead of publishing a duplicate.
- **macOS microphone picker** — real device names from the system, with saved
  selections resolved correctly and no phantom "Default Microphone" on
  machines without an input device.

## Fixes

- Fixed the Rust backend failing to compile on PipeWire < 1.0 headers (e.g.
  Ubuntu 22.04's `libpipewire-0.3-dev` 0.3.48): the `libspa` dependency is now
  vendored with a compatibility shim that supplies the missing meta helpers.
  On PipeWire >= 1.0 the code paths are identical to upstream.
- Keystroke capture no longer records shifted or AltGr typing — only genuine
  shortcut combinations — and captured segments align with recorded video
  time, not paused wall-clock time.
- A newer keypress now truncates the previous badge instead of erasing the
  portion already shown.
- Keystroke badges only replay through clips from the original recording —
  inserted b-roll never shows the capture's keystrokes.
- The keystroke-overlay toggle is disabled on Linux, where there is no input
  hook yet, instead of silently recording nothing.
- Hardened the YouTube sign-in flow: the loopback callback has a deadline,
  parameters are parsed correctly, only one flow runs at a time, and failures
  are reported accurately.
- Fixed caption sidecar cue times not being shifted by intro-card duration.
- Fixed export jobs in different projects being able to occupy the same
  output path — destinations are now deduplicated globally.
- The frame writer on macOS no longer hangs when the encoder stalls or fails
  to spawn — stopping a capture always stays responsive.
- The keystroke toggle, audio, and cursor panels now share the same durable
  export settings as the Finishing panel instead of drifting apart.
