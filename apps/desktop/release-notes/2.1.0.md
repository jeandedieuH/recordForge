# RecordForge 2.1.0

## Highlights

- **More reliable brand card exports** — attaching intro/outro brand cards no
  longer fails when the temp folder and the output are on different drives,
  when audio can't be probed, or when the partial was produced by a different
  encoder than expected.
- **Missing brand assets now warn you** — if a saved logo or font file was
  moved or deleted, the brand watermark card shows a warning instead of
  silently exporting without it.

## Fixes

- Fixed brand card muxing failing across drives by copying instead of
  renaming into place.
- Fixed concat breakage on audio-bearing exports when audio probing fails;
  exports fall back to 48 kHz stereo.
- Brand cards now encode with the same codec parameters as the partial so
  stream-copy concatenation succeeds.
- Brand cards are no longer applied to GIF/WebP exports.
