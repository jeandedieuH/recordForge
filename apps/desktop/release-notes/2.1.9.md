# RecordForge 2.1.9

## Improvements

- Hardware-accelerated exports now work on Linux via VAAPI, with automatic
  fallback to software encoding when VAAPI is unavailable — exports keep
  working on systems without compatible GPU drivers.
- Export output resolution is now capped correctly on all encoder paths,
  so hardware-accelerated exports respect the same limits as software
  encodes.

## Fixes

- Google Drive uploads now reliably resolve the target folder: folders are
  found or created as needed, and configuration problems are reported up
  front instead of failing mid-upload.
