# RecordForge 2.3.11

## Highlights

- **End cards that actually work.** Titles, annotations, and images can now
  extend past the last frame of footage. The preview holds the final frame
  while your outro animates, and export does the same on both renderers —
  the screen stream is padded with its last frame while the overlay plane
  keeps playing, including on the GPU export path and in chunked renders.
- **Presets that scale with your canvas.** Title and annotation presets are
  authored for 1080p and now scale to the project canvas, so a 4K recording
  no longer gets hairline strokes or undersized titles. Custom presets saved
  before this change are migrated automatically.

## Improvements

- **Dragging overlays is smoother.** Moving or resizing an annotation now
  patches the retained overlay scene in place instead of rebuilding it on
  every pointer frame, and typing annotation text is debounced so the
  canvas stays responsive during edits.
- **Preview matches export more closely.** Connector, arrowhead, and shape
  shadows now rasterize identically in the native export, and text wrapping
  handles unbroken words the same way in both renderers.

## Fixes

- Adding an annotation while its track is muted now shows a hint to unmute
  it, instead of the annotation silently missing from preview and export.
- The legacy "draw-on" intro is relabelled "Fade" in the UI — it was always
  an opacity fade, and new clips no longer offer it under a misleading name.

## Internal

- The render plan extends `durationMs` to the overlay content end; the
  FFmpeg path pads the screen stream with `tpad=clone` while captions and
  masks clamp to real screen frames, long tails merge into the last screen
  chunk, and the GPU decode pass holds the final frame via
  `tpad=stop_mode=clone`. Mid-timeline gaps still fall back to the
  compatibility renderer.
- `OverlayEngine::update_item_geometry` patches transforms and connector
  endpoints on the retained WASM scene for drag/resize gestures; style,
  timing, or item-set changes still rebuild through full validation.
- New golden-frame benchmark suite (`tooling/benchmarks/golden-frames.ts`)
  compares exported MP4 frames against checked-in PNGs with PSNR/SSIM,
  plus an overlay-drag rebuild-vs-patch benchmark.
- Regression coverage for tail playback, the GPU tail gate, preset scaling,
  and design-scale migration across `editor-core`, `media-core`,
  `overlay-core`, and `overlay-engine`.
