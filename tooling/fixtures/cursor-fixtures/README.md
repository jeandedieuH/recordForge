# Cursor Fixture Bundle

This directory contains deterministic, checked-in cursor telemetry fixtures for editor and cursor Phase 0. Fixtures are generated by `generate.ts` and committed so consumers do not need to regenerate them unless the recipe changes.

## Regenerate

```bash
bun run tooling/fixtures/cursor-fixtures/generate.ts
```

## Invariants

- All coordinates are deterministic and reproducible.
- No fixture contains user media, secrets, or absolute machine paths.
- V2 fixtures are backward-compatible with V1 consumers for the base fields.
- New V2 fields are ignored by the current V1 `cursorTelemetryFileSchema` because it is not strict.
